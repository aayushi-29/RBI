**The real next step, per `docs/DECISIONS.md` D-009's own "Consequences" note, is unchanged in substance: breaking the circularity caveat.** The 127 gold items are internally consistent (the resolver agrees with data originally generated from itself) but not yet proof of real-world correctness. That requires benchmark items whose expected outcome is derived independently of the resolver — e.g. a qualified reviewer answering from the primary RBI/SEBI source text alone, never seeing the resolver's output — per `docs/PENDING_TWO_PERSON_VERIFICATION.txt`'s "Circularity caveat" section. Concretely, on the `1st-Round-of-Changes` branch this is being approached by:
1. Drafting new candidate items (status `draft`, never `gold_verified`) that are stratified across regulation areas, outcome types, and amendment history per `docs/DATASET_SPEC.md` / `docs/RESEARCH_EVALUATION.md`, including genuine `Conflict` candidates per D-004's rule (authoritative sources must actually disagree with no documented precedence; no invented priority numbers).
2. Routing those drafts through the same two-independent-annotator + source-text-adjudication process as D-007–D-009, which requires real human annotators — this cannot be done by the assistant alone without repeating the D-005 weakening this project has already explicitly rejected.
